=== データ製品の名称

データ製品の名称は、「``3D都市モデル\_[都市コード]_[提供者区分]\_[整備年度]_[オプション]``」とする。
// データ製品の名称は、「``3D都市モデル_[都市コード]_[提供者区分]_[整備年度]_[オプション]``」とする。
